# Third-party notices for `rink/hk001/`

The HK001 port reproduces what a Go program does, so parts of it are ports of the Go standard library and carry
data taken from it. This file lists them and keeps the notices their licences ask for. HK001 itself (the engine's
equations, the input adapter's format rules) is the package owner's own work and is not covered here.

## What comes from Go

| file | what was ported or taken | Go source |
|---|---|---|
| `gomath.js` | `math.Exp` (both amd64 code paths), `math.Log`, `math.Pow`, `math.Cos`, `math.Frexp`/`Ldexp`/`Modf`: constants and operation order | `src/math/exp_amd64.s`, `log_amd64.s`, `log.go`, `pow.go`, `sin.go` |
| `adapter.js` | `encoding/csv` `Reader.readRecord`; `encoding/xml` `Decoder` (tokenizer, name and character rules) and the part of `Unmarshal` two structs use; `encoding/json` scanner (`checkValid`) and its error text; `bufio.Scanner`'s line limit; `html.UnescapeString`; `strconv.ParseFloat` (`readFloat`, `atofHex`, `eiselLemire64`, `underscoreOK`), `strconv.Quote`; `strings.ToLower`, `TrimSpace` | `src/encoding/csv/reader.go`, `src/encoding/xml/xml.go`, `read.go`, `src/encoding/json/scanner.go`, `src/bufio/scan.go`, `src/html/escape.go`, `src/strconv/atof.go`, `eisel_lemire.go`, `quote.go`, `src/strings/strings.go` |
| `engine.js` | `encoding/json`'s string encoding and map key order (`appendString`); `strings.EqualFold` against an ASCII word | `src/encoding/json/encode.go`, `src/strings/strings.go` |
| `go-tables.json` | the simple lower-case mapping of `unicode.ToLower` (Unicode 15.0.0), generated by running Go; the two XML 1.0 name-character range tables of `encoding/xml` | `src/unicode/tables.go`, `src/encoding/xml/xml.go` |
| `html5-entities.json` | the HTML named character reference table | `src/html/entity.go` |

The ports are JavaScript rewrites, statement by statement where the behaviour depends on it. They are checked
against Go itself: `tests/rink/gomath.test.js`, `tests/rink/hk001.test.js`, `tools/rink/hk001-difftest.js` and
`tools/rink/adapter-difftest.js`.

## Data

- The lower-case mapping in `go-tables.json` is derived from the Unicode Character Database (Unicode 15.0.0),
  copyright Unicode, Inc.; for its terms of use see https://www.unicode.org/terms_of_use.html.
- The name-character ranges in `go-tables.json` are the character classes of Appendix B of the W3C Recommendation
  "Extensible Markup Language (XML) 1.0", as tabulated in Go's `encoding/xml`.
- `html5-entities.json` is the named character reference table of the WHATWG HTML Living Standard
  (https://html.spec.whatwg.org/multipage/named-characters.html), as tabulated in Go's `html` package.
