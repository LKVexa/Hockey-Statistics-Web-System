The workbench window

The window is a scorer's console on the left and the game it is building on the right. Everything typed in it runs in the engine in the window; everything it changes is recorded by the host before it is shown.

The host strip

The strip is the window's statement of where the league is. It names this laptop's static loopback address and the device it belongs to (the first digits of the laptop's identity), the number of teams and games in the league, and the recording state:

StateMeaning
opening…, league loadedThe window is loading the league from the host, or has loaded and replayed it
recording… (amber)A commit is on its way to the host; the command's result is not yet shown
recorded and a time (green)The host has synced everything the last command changed
NOT RECORDED (red)The host refused a commit or could not be reached; the window has loaded the league again ({{ref:refused}})
host stopped (red)The host was stopped from the window; the league is on disk and the window can be closed

verify store runs store verify ({{ref:store-commands}}). stop host commits anything outstanding and stops the host ({{ref:stopping}}).

The command line and its assistance

The prompt is rink-vt › outside RINK mode. In RINK mode it is the game's state: rink G1 FOCO 0–0 KELW P1 20:00⏸ 5v5 › — the game, the score, the period and clock (▶ running, ⏸ stopped) and the strength. As a line is typed, the engine's assistant analyses it on every keystroke and the line takes one of four states.

StateMeaning and hint
emptyThe hint lists the common forms: in RINK mode TEAM PLAYER STAT · Q BOX · LINE … · T 20:00 P1 · START · GO · WHISTLE (Esc) · UNDO · EXIT · help
incomplete (amber)The line can still become valid; the hint names what comes next and the first candidates
validThe line can be run as it stands; grey ghost text may offer a completion
invalid (red)The line cannot become valid; the hint gives the reason (an unknown player, a modifier the stat does not take, a team that is not playing)
KeyAction
EnterRuns the line. Its keystroke onset — the time of the first character — is kept and becomes the frame's onset time, so the clock latches at the keystroke, not at Enter
TabCompletes: in RINK mode the assistant's completion; outside it, the command name and a space
→ or End at the end of the lineAccepts the grey ghost text
↑ ↓Moves through the lines typed in this window
EscThe whistle: while the selected game's clock runs, stops it at the moment the key goes down, as WHISTLE does, from the command line or anywhere in the window; whatever is half-typed on the line stays there. With the clock stopped Esc changes nothing, and the hint says so ({{ref:clock}})

In RINK mode a line that is not a line of the scorer's language — hk001, OFF-001, rink games — runs as an ordinary command. Outside RINK mode, a command typed in capitals (Q BOX) is the same as in lower case (q box).

Chips

The chips below the console type a command as if it were typed and entered: rink games, rink new FOCO KELW, rink sim 4, Q STANDINGS; scoring lines such as T 20:00 P1, START, GO, WHISTLE, FOCO SMIT S/2W, UNDO; queries; HK001 commands such as OFF-001 and case team FOCO --season; roster commands; and store and store verify. A chip is a convenience: what it types is recorded exactly as the same line typed by hand.

The game panel

The score bar shows the selected game's teams and score, the period, the clock (counting down while it runs; ⏸ whistle when a whistle stopped it), the strength and the penalties being served. Until the game's start frame it adds not started: START at the opening faceoff, and the clock does not move ({{ref:clock}}). The rink shows every shot (○) and goal (●) of the game except the shootout, each sized by its expected-goals value, home attacking to the right; beneath them lies a heat map of the attempts (a box-kernel density of about 15 ft). Clicking the rink appends the clicked coordinates to the command line as /x,y in feet, mirrored for the away team so that the coordinates are always those of the team typed.

The tabs show, for the selected game: frame, the bytes of the frames the last line compiled to, field by field and colour-coded, with the CRC-32C checked ({{ref:frame}}); box, each team's totals (shots on goal, expected goals for, Corsi for, high-danger chances for) and every skater with goals, assists, points, shots, individual expected goals and time on ice; events, the last forty events with clock, text, assists, expected goals and strength; and league, the standings with games played, wins, losses, overtime losses, ties (once a tie stands), points, goals and expected goals for and against.

Workbench commands

Four commands belong to the window rather than to the engine.

CommandEffect
storePrints the product, version, edition and engine version; the runtime (the host's platform, for example Photon host · native windows/amd64 executable · no Python, no Node.js); this laptop's loopback address and device, the pool and the address listened on when it differs; the laptop's pinned address when this league holds another one for it; the fleet register and its state, or that there is none; the data folder, the number of games and the number of host events
store verifyAsks the host to re-read the whole league from disk and check every seal and chain, repairing nothing, and prints OK or DAMAGED; the registry's seal; the event ledger's length; and, per game, its number of entries, its chain and the first digits of its tip hash ({{ref:verification-report}})
helpLists the workbench's commands. In RINK mode, HELP lists the whole scorer's language
clearClears the console

Roster files from this computer

The chip your roster file… opens the system's file chooser for a file in one of the eight roster forms (.csv .tsv .xlsx .md .txt .corpus .xml .edi). The file is read in the window — it never travels to the host as a file — and handed to the engine's importer under its name, after which the window runs rink import NAME: a preview of what the file holds and the four-letter reference each league, team and player would receive. rink import NAME --apply registers it, and the registry change is recorded like any other ({{ref:rosters}}). rink import examples writes seven example files into the window's own file system, under rosters/.
