Revision history

Revision 1.3 · {{issued}}The Photon host is a native program: one executable per platform (Windows, macOS and Linux, each on x64 and ARM64), written in Go with its standard library only, so that there is no Python and no Node.js anywhere in the edition and nothing to install. The launchers start the executable; verification, leases, the bundle, the seal, the contracts and this guide are commands of the same executable; the tests are Go tests. File formats, addresses and leagues are unchanged, and a league written by an earlier release opens as it was (Chapters 1–5, 8–12, 15–19, Appendices F and G, the contracts), with RINK-VT {{version}}.
Revision 1.2 · {{issued}}The whistle: WHISTLE [mm:ss] and Esc stop the clock when the whistle goes, at the official clock's time when one is given (Chapters 3, 5, 6, 12, 14). League overtime rules: rink overtime, six presets and settings for the overtime's length and strength and the shootout's rounds, copied into each game at its creation; ties and their standings column (Chapters 2, 6, 14, 17–19, Appendix G, the contracts and the new JA source rinkvt_overtime.ja), with RINK-VT 2.5.0-lkvexa.3.
Revision 1.1 · {{issued}}The start frame: a new game's clock waits for START, the opening faceoff (Chapters 3, 5, 6, 12, 14). Every laptop keeps its own static 127 address, leased to the laptop rather than to its IP address: device identity, device file, pin, fleet register, conflicts, lease table format 2 (Chapter 9 rewritten; Chapters 2–5, 10–13, 15, 17–19, Appendix G and the contracts updated), with RINK-VT 2.5.0-lkvexa.2.
Revision 1.0 · {{issued}}Initial issue, with RINK-VT 2.5.0-lkvexa.1 (the LK/Vexa edition's first release) and the reference edition {{reference}}.

Conventions

Requirement keywords. The key words MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, NOT RECOMMENDED, MAY and OPTIONAL in this document are to be interpreted as described in BCP 14 (RFC 2119, RFC 8174) when, and only when, they appear in all capitals. Statements of what the software does are descriptions of the release, verified by the tests named in Chapter 17; statements with these key words are obligations on the operator, the administrator or a maintainer.

Requirement identifiers. Numbered obligations carry an identifier of the form OPS-07 (operation), DAT-03 (data custody), SEC-02 (security) or MNT-04 (maintenance), so that a local procedure or an audit can cite them.
