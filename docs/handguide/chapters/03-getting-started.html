Getting started

This chapter takes an operator from a downloaded release to a first scored game and a verified league. Each procedure is complete in itself; Part II explains every step in detail.

Obtaining the release

The LK/Vexa edition is published as a Git repository and may be distributed as an archive of it. Either way, the release is a folder holding START_RINKVT.cmd, START_RINKVT.sh, photon/ with the host for each platform in photon/bin/, ui/, engine/ and RELEASE_MANIFEST.json among others ({{ref:module-map}}).

Every byte of the release is sealed. A Git client that converts line endings on checkout (on Windows, core.autocrlf=true) would change the files and the host would refuse to start (exit code 4). The repository's .gitattributes disables conversion for every file; a copy made by other means MUST keep the files' bytes as they are.

Place the folder where the operator can write: the default data folder, runtime/, is created beside the program on the first start. A path without unusual characters, such as C:\RINK-VT\ or ~/RINK-VT/, avoids surprises with long or synchronised paths.

First start on Windows

  1. Double-click START_RINKVT.cmd in the release folder. It starts the Photon host for this computer — photon\bin\rinkvt-photon-windows-amd64.exe, or …-windows-arm64.exe on an ARM64 computer — in a console window, which prints the start report ({{ref:start-sequence}}). Nothing is installed first, and nothing has to be.

  2. If Windows SmartScreen says that it protected the PC from an unrecognised app, choose More info, then Run anyway. The executables are not code-signed; their SHA-256 digests are sealed in RELEASE_MANIFEST.json ({{ref:manifest}}). Unblocking the downloaded zip before unpacking it (its Properties, Unblock) avoids the question.

  3. The workbench opens in an Edge or Chrome window of its own. The header strip shows loopback 127.x.y.z · static for device and the first digits of this laptop's identity, and league loaded. The address belongs to this laptop and stays the same on every network ({{ref:loopback}}).

  4. Keep the console window open while working: it is the host. Closing it stops the host; what was recorded stays recorded.

First start on macOS and Linux

  1. In a terminal, run ./START_RINKVT.sh from the release folder. It starts the host for this system and processor — photon/bin/rinkvt-photon-darwin-arm64, …-linux-amd64 and so on — and makes it executable first if the unpacker dropped that permission.

  2. On macOS, a release downloaded with a browser is quarantined, and the system will not run a program from an unidentified developer. Clear the quarantine once with xattr -dr com.apple.quarantine on the release folder, or allow the program in System Settings, Privacy & Security.

  3. The workbench opens in Edge, Chrome or Chromium. On macOS the start report says that the system answers only on 127.0.0.1 and that the host listens there; the lease is still made and recorded ({{ref:platforms}}).

  4. Leave the terminal open; Ctrl+C stops the host.

A first session

On its first start the host finds no league, and the window seeds the four demonstration clubs (FOCO, KELW, RIMO and SASK, all fictional) and records them. The following session scores the opening of a game, queries it, and checks the league.

rink new FOCO KELW              creates game G1 between the two clubs and selects it
rink G1                         enters RINK mode; the prompt shows the score and the clock
T 20:00 P1                      sets the scoreboard clock: 20:00 in the first period
LINE FOCO SMIT HALA GOUL VAHN MORE    FOCO's skaters on the ice
LINE KELW BARK WITC DELI EMBE ZIEL    KELW's skaters on the ice
START                           the start frame: the opening faceoff; the clock runs from here, never before
FOCO SMIT FOW/N                 FOCO's SMIT wins the opening faceoff in the neutral zone
FOCO GOUL S/1W                  a wrist shot from zone 1: expected goals and danger class
FOCO SMIT G/2P                  a goal: score, plus/minus, stint rotation
FOCO HALA A                     the primary assist, chained to the open goal
WHISTLE                         the whistle: the clock stops (Esc does the same)
FOCO SMIT FOW/N                 the faceoff at centre ice
GO                              the clock runs again
KELW BARK P2/TRP                a two-minute minor for tripping: FOCO goes 5 on 4
Q BOX                           the box score
Q AUDIT                         every line, who typed it, from which loopback address
EXIT                            leaves RINK mode
store verify                    re-reads every seal and chain of the league from disk

Each line answers with its outcome — COMMITTED, APPLIED, REJECTED with a reason, or DUPLICATE — after the host has recorded it. The header strip shows recorded and the time. rink sim 4 types four synthetic games through the same command path, so that every query and model has data at once.

Stopping the host

The host stops on Ctrl+C in its console, on stop host in the window's header strip, or when its console is closed. Every recorded line is already on disk when it is acknowledged, so stopping loses nothing that was shown as recorded. The host records the stop in its event ledger and releases the data folder ({{ref:stopping}}).

Several laptops

Each laptop that runs the workbench receives its own static 127 address on its first start, and keeps it. To make sure that no two laptops of a club or league can ever hold the same address, whichever leagues they open, enrol them all once in a shared fleet register: START_RINKVT.cmd --fleet E:\rinkvt\fleet-leases on each laptop, or RINKVT.cmd leases --enroll E:\rinkvt\fleet-leases (./rinkvt.sh on macOS and Linux) ({{ref:fleet}}).
