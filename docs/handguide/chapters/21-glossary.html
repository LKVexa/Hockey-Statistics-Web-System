Glossary

Actor
The event-sourced game state machine: a pure fold of a game's accepted frames ({{ref:actor}}).
Assistant
The part of the engine that classifies a line as it is typed and offers ghost text and candidates.
Audit trail
Every line of a game with its operator, source, loopback address and outcome (Q AUDIT).
Base
The registry seal a window last saw, carried by each commit; a stale base is refused.
Bundle
ui/workbench.js: the module loader holding the engine, the rink drawing and the page, built by tools/bundle.py.
Capacity
The number of addresses a lease pool holds: 254 per /24 it contains.
Chain
The sequence of hashes linking every line of a ledger to the line before; its last hash is the tip.
Commit
One request by which the window sends the host what a command changed; recorded before it is answered.
CRC-32C
The Castagnoli cyclic redundancy check (RFC 3720 Appendix B.4) sealing every frame and meta line.
Cut-off line
A last line of an append-only file without its newline, left by a stop during a write; never acknowledged, dropped when the file is opened. Also torn line.
Data folder
The folder holding the league, the event ledger, the lease table and the window's browser profile.
Danger class
HIGH, MEDIUM or LOW, by location and flags (RINKVT-DANGER-v1).
Edition
One of the two forms of RINK-VT: the LK/Vexa edition (Photon-hosted) and the reference edition (HERMIT).
Engine
The language, frames, actor, queries, models, roster importer and HK001 port, shared by both editions.
Event ledger
events.jsonl: the host's own hash-chained record of starts, commits and stops.
Frame
A 64-byte record of one fact, the unit the ledger keeps ({{ref:frame}}).
Genesis
The hash that precedes a ledger's first line, derived from the game's key and UUID.
HK001
A deterministic synthetic research laboratory (MSSL 2.3.0), ported exactly from Go; 563 computation codes and 109 inputs.
Host
Here, the Photon host: the Python program that keeps the league and serves the workbench.
JA21
The JA21 language suites; here, JA Core 0.3 in its provisional grammar, used for modeled contracts.
Device file
The per-user file in which a laptop keeps its device key, its pinned address and its fleet register ({{ref:device-file}}).
Device key
A laptop's identity: device: and 32 hex digits, an HMAC-SHA-256 digest of its machine identifier.
Fleet register
A lease table every laptop of a club or league shares, which makes their addresses unique everywhere ({{ref:fleet}}).
Key
What a lease belongs to: a laptop's device key, or, in the reference edition, the canonical text of an IP address.
Lease
The static loopback address a laptop (in the reference edition, a client IP address) receives and keeps.
Machine identifier
The operating system's own identifier of the computer (MachineGuid, IOPlatformUUID, machine-id), read but never stored.
Ledger
A game's append-only record of frame and meta-line pairs.
LK/Vexa
The ecosystem of languages and tools (MSSL, JA21, Photon) in which this edition is built and described.
Manifest
RELEASE_MANIFEST.json: the SHA-256 of every file of the release.
Meta line
The 64-byte record stored with each frame: index, time received, source, operator and loopback address ({{ref:meta}}).
MSSL
The language of the MSSL Writers Corpus; here, its observed 0.3 subset, used for sealed component records.
NOT RECORDED
The window's statement that a commit was refused or failed and that the league was loaded again.
Operator
The person running the workbench; in this edition, the identity operator@local.
Overtime rules
What decides a game level after regulation: the overtime's length and strength and the shootout's rounds, in a regular and a playoff block; set per league, copied into each game at its creation ({{ref:overtime}}).
Pin
The address a laptop keeps in its device file and asks for in every lease table it meets ({{ref:pin}}).
Pair
A frame and its meta line: 128 bytes, one line of a ledger file.
Photon
VEC1 Photon: the design of a Python control plane with a Chromium-family renderer that this edition's host follows.
Pool
The part of 127.0.0.0/8 from which leases are drawn; by default 127.16.0.0/12.
Preset
A named set of overtime rules: standard, four-on-four, international, overtime-then-tie, shootout-only, ties.
Qualification
The record of a test run of the release, written by tools/contracts.py qualify.
Registry
The sealed JSON document of leagues, teams, players, games and notes.
Renderer
The browser window in which the workbench and the engine run.
RINK mode
The mode of the command line in which lines of the scorer's language are scored into the selected game.
Seal
A digest that a file or record must match: the registry's SHA-256, a lease line's 16-digit seal, an MSSL record's κ.
Slot
The position in a pool that a key's hash selects as its first choice.
Start frame
The START line: the opening faceoff, from which a game's clock runs ({{ref:clock}}).
Stint
A stretch of play with fixed personnel and state, the unit of RAPM.
Tie
A game that ends level where its overtime rules let a tie stand; one point to each side.
Tip
The last hash of a ledger's chain, summarising the whole ledger.
Token
The 256-bit secret drawn at each launch, required by every API route but health.
UUIDv7
A time-ordered UUID (RFC 9562), the identity of every frame.
Whistle
The WHISTLE line, or Esc: the clock stops when the whistle goes, at the official clock's time when one is given ({{ref:clock}}).
xG, x̃G
Expected goals; flurry-discounted expected goals ({{ref:xg}}).
